HARDWARE SETUP REQUIREMENTS:
================================================================================

1. COMPARATOR INPUTS (CRITICAL):
   
   PA1 (COMP1+) → Motor Phase A through resistor divider:
   
        Motor Phase A ----[ 10kΩ ]---- PA1 ----[ 10kΩ ]---- GND
   
   PA5 (COMP1-) → Virtual Neutral / Reference Voltage:
   
        Vbus ----[ 10kΩ ]---- PA5 ----[ 10kΩ ]---- GND
   
   This creates Vbus/2 reference (~1.65V if Vbus = 3.3V logic level)
   
   ⚠️ WITHOUT THESE CONNECTIONS, COMPARATOR WILL NOT WORK!

2. MOTOR CONNECTIONS:
   - Phase A: PA8 (high-side PWM) + PA7 (low-side GPIO)
   - Phase B: PA9 (high-side PWM) + PB0 (low-side GPIO)
   - Phase C: PA10 (high-side PWM) + PB1 (low-side GPIO)

3. RC INPUT:
   - PA6 (TIM3_CH1) connected to RC receiver signal

4. DEBUG LED:
   - PC13 (onboard LED)


TIMER ARCHITECTURE VERIFICATION:
================================================================================

Timer Role Map (Must Match AM32):

┌─────────┬──────────────────────┬────────────┬─────────────────────┐
│ Timer   │ Function             │ Prescaler  │ Tick Period         │
├─────────┼──────────────────────┼────────────┼─────────────────────┤
│ TIM1    │ PWM Generation       │ 0          │ 20.8 ns (48MHz)     │
│ TIM2    │ ZC Interval Measure  │ 47         │ 1 µs                │
│ TIM3    │ RC Input Capture     │ 47         │ 1 µs                │
│ TIM14   │ Commutation Schedule │ 47         │ 1 µs                │
└─────────┴──────────────────────┴────────────┴─────────────────────┘

Key Difference from Your Old Code:
  ✅ TIM2 is NOW dedicated to zero-crossing timing (resets on each ZC)
  ❌ OLD: Used TIM3->CNT for ZC timing (caused overflow issues)
